# Changelog

Все важные изменения проекта документируются в этом файле.

## [1.7.0] - 2026-10-20

### Added
- Полная адаптация витрины (`index.html`) для мобильных устройств: планшеты, смартфоны и альбомная ориентация.
- Плавающая кнопка быстрого закрытия `✕` (`.modal-close-icon-btn`) в верхнем правом углу модального окна просмотра карточки.
- Адаптивные названия кнопок шапки (`Sugar Rush: Super Scatter` -> `Sugar Rush` -> `Слот`; `В предложку` -> `Предложка`) со ступенчатым сокращением на малых экранах.
- Поддержка горизонтального поворота смартфонов (`@media (max-height: 500px) and (orientation: landscape)`).

### Changed
- Переработано модальное окно просмотра кадра (`#card-modal`): на мобильных экранах горизонтальный макет переключается на вертикальный стек (`flex-direction: column`), устранено сжатие фото сайдбаром, кадр центрируется с пропорциями `object-fit: contain` и высотой `48vh`.
- Кнопки управления в модалке выстроены в компактную 2-колоночную сетку («Править» / «Удалить») с полноразмерной кнопкой «Закрыть».
- Сетки галереи (`.gallery-grid`) и вестника новостей (`.articles-grid`) оптимизированы для аккуратного перестроения в 1 колонку.
- Задан размер шрифта $16\text{px}$ для полей ввода форм на мобильных для предотвращения автоматического зума страницы в iOS Safari.
- Актуализирована документация в `README.md`.

## [1.6.0] - 2026-10-20

### Added
- Реализован дабл-тап (двойной клик/тап) по статьям клубного вестника для быстрой установки лайка/сердечка с анимацией вылетающего 3D-сердечка ❤️ и мгновенным инкрементом счетчика.

### Changed
- Страницы `index.html` (публичная витрина) и `admin.html` (панель модератора) перенесены из подкаталога `pages/` напрямую в корень проекта.
- В `index.html` и `admin.html` скорректированы все относительные пути к ресурсам (`images/symbol.png`, `data/data.json`, `data/articles.json`, `data/config.json`) и функции разрешения путей `resolveImagePath`.
- Упразднен промежуточный редирект, упрощена структура веб-узла для GitHub Pages и локального сервера.
- В `scripts/admin_server.py` обновлена маршрутизация запросов (с сохранением обратной совместимости для старых URL `/pages/*`).
- Обновлены автотесты в `tests/test_data_integrity.py` и документация в `README.md`.

## [1.5.0] - 2026-10-20

### Added
- Добавлен ряд из 5 эмодзи-реакций (❤️ Сердечко, 🍓 Клубничка, ⚡ Молния, 💩 Какашка, 🖕 Фак) в левый нижний угол карточек галереи и в боковую панель модального окна.
- Реализована функция двойного тапа (дабл-тап) по карточке и фото в модалке для быстрой установки сердечка с вылетающей 3D-анимацией.
- Снята защита от накрутки: теперь каждое нажатие на реакцию или дабл-тап всегда инкрементирует счетчик (+1) без ограничений.

### Changed
- Привязка блока реакций карточки переведена с текста описания на нижний край карточки (`margin-top: auto`), обеспечивая равномерное выравнивание по сетке.
- Актуализирована документация `README.md`.

## [1.4.0] - 2026-10-20

### Added
- Добавлена система лайков в реальном времени для фото-карточек галереи, модального окна просмотра и клубных статей на базе Firebase Realtime Database.
- Реализован оптимистичный UI с мгновенным визуальным откликом, плавной bounce-анимацией и локальным кэшированием отметок в `localStorage` (`gazmyas_liked_posts`).
- Настроена живая двусторонняя синхронизация счетчиков между всеми клиентами через Server-Sent Events (SSE / `EventSource`) без перезагрузки страницы.
- Реализована безопасная потокобезопасная отправка с атомарным серверным инкрементом (`.sv: {"increment": delta}`) и очисткой ключей (`getSafeFirebaseKey`).
- Обновлена документация и схема архитектуры в `README.md`.

## [1.3.0] - 2026-10-20

### Added
- Системный промпт AI-куратора вынесен в отдельный локальный файл `prompt.txt` (включен в `.gitignore`).
- Добавлен публичный шаблон `prompt.example.txt` для репозитория на GitHub без персональных замечаний и локальных шуток.
- В `auto_curator.py` реализована функция `load_prompt()` с поддержкой переменной `CURATOR_PROMPT_FILE` и автоматическим фолбэком на шаблон.
- Добавлен автотест `test_prompt_configuration` в `tests/test_data_integrity.py` для контроля валидности шаблона промпта и отсутствия приватных замечаний.

### Changed
- В `.gitignore` добавлены правила исключения персональных промптов `prompt.txt` при сохранении отслеживания `prompt.example.txt`.
- Актуализированы `.env.example` и `README.md` с описанием настройки и кастомизации промпта.
