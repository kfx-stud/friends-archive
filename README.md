## 📌 О проекте

Проект стилизован под сайт футбольного клуба с локальным комьюнити-юмором. Система полностью берет на себя рутину разбора сотен фотографий из чатов Telegram:

1. **Мультимодальный AI-анализ:** Нейросеть Gemini сканирует входящие файлы, оценивает уровень вайба (1–10) и генерирует едкие мемные панчлайны по клубным корзинам.
2. **Фильтрация и оптимизация:** Превью Telegram отсекаются, а качественные кадры (балл >= 5) сжимаются через Pillow до 1200x1200px (JPEG 85%) для моментальной загрузки с мобильных устройств.
3. **Штаб модерации (admin.html):** Быстрый отбор кадров с клавиатуры, интерактивный выбор фокуса кадрирования (object-position) кликом по снимку и редактор статей клубного вестника.
4. **Двусторонний облачный буфер:** Связка со статическим хостингом через JSONBin.io для приема пользовательских заявок («В предложку», «Править описание», «Удалить»).
5. **Интерактивная витрина:** Просмотр полного кадра без обрезки с боковой панелью описания, блок клубных статей и встроенный слот Sugar Rush 7x7 с Tumble-каскадами и множителями до x128.

## ⚡ Ключевые возможности

| Функция | Модуль / Компонент | Назначение |
| :--- | :--- | :--- |
| **AI-Курирование** | `auto_curator.py` | Оценка снимка от 1 до 10, генерация заголовка, панчлайна и тега через Gemini Flash |
| **Динамический пул AI** | `GeminiKeyManager` | Ротация пула API-ключей и адаптивная задержка ($12 / N$ сек, ускорение до 24x) |
| **Дедупликация** | `calculate_sha256` | Хэширование файлов для исключения повторной обработки дубликатов |
| **Удаление мусора** | `is_telegram_thumb` | Автоматический отсев превью Telegram (`_thumb` и файлы < 15 КБ) |
| **Сжатие графики** | `Pillow (PIL)` | Оптимизация исходников до 1200x1200px (JPEG 85%) |
| **Интерактивный фокус** | `admin.html` | Выбор точки внимания карточки кликом по фото (сохранение `crop_x` и `crop_y`) |
| **Редактор статей** | `admin_server.py` | Создание, редактирование и удаление материалов вестника (`data/articles.json`) |
| **Пагинация и скролл** | `index.html` | Порционная выдача по 12 карточек с кнопкой «Показать еще» и `IntersectionObserver` |
| **XSS-Санитизация** | `escapeHtml` / `Attr` | Полная экранизация карточек, статей и предложений пользователей на фронтенде |
| **Безопасное облако** | `JSONBin.io API v3` | Разделение прав: публичный `X-Access-Key` для предложки и приватный `X-Master-Key` в `.env` |
| **Изоляция бэкенда** | `admin_server.py` | Привязка к `127.0.0.1` и потокобезопасная синхронизация JSON через `threading.Lock()` |
| **Слот Sugar Rush 7x7** | `index.html` | Кластерная мини-игра: каскады Tumble, спот-множители до x128, покупка бонуски, Max Win 5000x |

## 🛠 Архитектура пайплайна

```text
[ Исходные фото / чаты Telegram ]
                 │
                 ▼
          📁 incoming/
                 │
                 ▼
          auto_curator.py
  ├─ Хэширование SHA-256 (отсев повторов)
  ├─ Фильтрация превью Telegram (_thumb, <15 КБ)
  ├─ Пул Gemini API (ротация ключей, темп 12/N сек)
  └─ Сжатие Pillow (1200x1200px, JPEG 85%)
                 │
        ┌────────┴────────┐
        ▼                 ▼
   (Score < 5)       (Score >= 5)
   📁 deleted/       📁 pending/ + 📄 data/pending.json
                          │
                          ▼
                Локальный штаб модерации
            (admin_server.py [127.0.0.1:8080] + admin.html)
        ▲                 │
        │ Опрос и очистка ├─ Одобрить [A] ──► 📁 images/ + 📄 data/data.json
        │ (X-Master-Key)  └─ В брак   [D] ──► 📁 deleted/
        │
   [ Облако JSONBin.io (Private Bin) ] ◄── Синхронизация статей и очереди
        ▲
        │ POST-запросы заявок (X-Access-Key: только запись в буфер)
        │
   [ Публичный сайт: index.html ] ◄── GitHub Pages (site.gasmyas.me)
```

## 🎛 Управление в панели модератора (`admin.html`)

* `[A]` или `Enter` — открыть настройку фокуса и одобрить карточку в основной состав.
* `[D]` или `Delete` — отправить снимок в брак (перенос в `deleted/`).
* **Клик по фото в модалке:** перемещает точку привязки кадрирования карточки (`crop_x`, `crop_y`) для мобильной сетки.
* **Вкладка «Заявки и Правки»:** утверждение предложений гостей сайта и удаление карточек по запросу.
* **Вкладка «Статьи»:** визуальный редактор новостей клуба с моментальным сохранением в `data/articles.json`.

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/kfx-stud/friends-archive.git
cd friends-archive
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения (`.env`)

Создайте файл `.env` в корне проекта (без пробелов вокруг знака `=`):

```ini
# Пул ключей Google Gemini API (через запятую для параллельного ускорения 12/N сек)
GEMINI_API_KEYS=AIzaSyA...,AIzaSyB...
GEMINI_MODEL=gemini-2.5-flash

# Приватный Master-Key JSONBin для админки (полный доступ: чтение и очистка очереди)
JSONBIN_BIN_ID=6abbe438ffd5...
JSONBIN_API_KEY=$2a$10$your_private_master_key_here...
```

> [!TIP]
> Для отправки пользовательских заявок («В предложку») на публичном сайте GitHub Pages используется отдельный ограниченный **Access Key** (только чтение/запись буфера предложки), зашитый в `index.html` и не дающий прав на чтение чужих данных или управление аккаунтом.

### 4. Рабочий процесс

1. **Сбор фото:** поместите новые фотографии в папку `incoming/`.
2. **AI-разбор:** запустите `run.bat` (или `python auto_curator.py`).
3. **Модерация:** запустите `admin.bat`, откройте `http://127.0.0.1:8080/admin.html`, настройте фокус на снимках и утвердите публикации.
4. **Деплой:** запустите `push.bat` для отправки изменений на GitHub Pages.
