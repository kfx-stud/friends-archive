# 📸 ФК ГазМяс - Автономный AI Медиа-Портал

Автоматизированный конвейер курирования, фильтрации, кадрирования, модерации и публикации медиа-архива на базе Google Gemini API и GitHub Pages.

Проект стилизован под сайт футбольного клуба с локальным юмором. Система автоматизирует разбор фотографий из чатов Telegram: мультимодальная нейросеть анализирует снимки, присваивает оценку вайба, генерирует ироничные описания, передает кадры в локальную панель модерации с визуальным кадрированием и публикует карточки на витрине клуба.

---

## ⚡ Ключевые возможности

- Автоматическое AI-курирование: Модель Gemini Flash оценивает снимки по 10-балльной шкале вайба и генерирует заголовок, мемное описание и тег по пяти тематическим корзинам.
- Отсев дубликатов и мусора: Вычисление SHA-256 предотвращает повторный анализ файлов, а эвристический фильтр удаляет превью Telegram (_thumb и файлы менее 15 КБ).
- Оптимизация трафика: Автоматический ресайз и сжатие снимков через Pillow (до 1200x1200px, JPEG 85%) для ускоренной загрузки страниц.
- Интерактивное кадрирование в админке: Перемещение прямоугольника с пропорциями карточки витрины (280x230) для настройки точки фокуса (object-position) с затемнением скрытой части фото.
- Быстрая модерация с клавиатуры: Управление очередью через хоткеи ([A] - одобрить в состав, [D] - отправить в брак).
- Двусторонняя связь через облако (JSONBin.io): Посетители сайта могут отправлять кадры в предложку или запрашивать удаление и правку карточек. Сервер модерации опрашивает облако каждые 25 секунд.
- Мини-игра Sugar Rush 7x7: Встроенный в сайт слот с кластерными выплатами от 5 символов, каскадами падений (Tumble), накапливаемыми спот-множителями до x128, покупкой бонуски за 100x и лимитом выигрыша 5000x.

## 🛠 Архитектура конвейера данных

```text
[ Исходные фото / чаты Telegram ]
                 │
                 ▼
          📁 incoming/
                 │
                 ▼
          auto_curator.py
  ├─ Проверка хэша SHA-256 (отсев дублей)
  ├─ Удаление превью Telegram (_thumb, <15 КБ)
  ├─ Анализ Gemini API (Score, Title, Tag, Caption)
  └─ Оптимизация через Pillow (JPEG 85%)
                 │
        ┌────────┴────────┐
        ▼                 ▼
   (Score < 5)       (Score >= 5)
   📁 deleted/       📁 pending/ + 📄 pending.json
                          │
                          ▼
                  Локальная админка
            (admin_server.py + admin.html)
        ▲                 │
        │ Опрос облака    ├─ Одобрить [A] ──► 📁 images/ + 📄 data.json
        │ (раз в 25 сек)  └─ В брак   [D] ──► 📁 deleted/
        │
   [ Облако JSONBin.io ]
        ▲
        │ POST-запросы («В предложку», «Правка»)
        │
   [ Сайт: index.html ] ◄── GitHub Pages (site.gasmyas.me)
```

## 🧰 Стек технологий

- Язык разработки: Python 3.10+
- AI Core: Google Gemini API (gemini-3.8-flash с ротацией пула ключей и паузами при ошибках 429/503)
- Обработка графики: Pillow (PIL)
- Облачный буфер: JSONBin.io REST API v3
- Фронтенд: Vanilla HTML5, CSS Grid / Flexbox, JavaScript ES6 (Fetch API, DOM Events)
- Хостинг: GitHub Pages + собственный DNS (CNAME)

## 🚀 Установка и настройка

### 1. Клонирование репозитория:
```bash
git clone https://github.com/kfx-stud/friends-archive.git
cd friends-archive
```

### 2. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 3. Конфигурация окружения:
Создайте в корне проекта файл .env:
```env
# Ключи Gemini через запятую для автоматической ротации
GEMINI_API_KEYS=AIzaSyA...,AIzaSyB...

# Рабочая модель
GEMINI_MODEL=gemini-3.8-flash

# Настройки прокси (если требуется для доступа к API)
# HTTP_PROXY=http://127.0.0.1:10809
# HTTPS_PROXY=http://127.0.0.1:10809
```

## 🔄 Ежедневный рабочий процесс

1. Загрузка фото: Поместите новые снимки в папку incoming/.
2. AI-анализ: Запустите run.bat (или команду python auto_curator.py). Кадры с оценкой от 5 баллов попадут в pending/.
3. Модерация: Запустите admin.bat. В открывшейся вкладке (http://localhost:8080/admin.html):
   - Во вкладке «Очередь» настройте положение рамки кадрирования на фото и нажмите [A] (Одобрить) или [D] (В брак).
   - Во вкладке «Заявки посетителей» проверьте пришедшие предложения и правки, отредактируйте текст при необходимости и нажмите «Применить».
4. Публикация: Запустите push.bat. Изменения запишутся в Git и через 1-2 минуты отобразятся на сайте site.gasmyas.me.
