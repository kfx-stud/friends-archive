# 📸 ФК ГазМяс — Автономный AI Медиа-Портал

Автоматизированный конвейер курирования, фильтрации, кадрирования, модерации и публикации медиа-архива тусовки на базе Google Gemini API и GitHub Pages[cite: 7].

Проект стилизован под сайт футбольного клуба с локальным юмором[cite: 7]. Он полностью снимает задачу ручного разбора сотен фотографий из чатов Telegram[cite: 7]: мультимодальная нейросеть анализирует снимки, присваивает оценку вайба, генерирует ироничные панчлайны, отправляет кадры в локальную панель модерации с визуальным кадрированием и публикует готовые карточки на витрине клуба[cite: 1, 7].

---

## ⚡ Ключевые возможности

* **Автоматическое AI-курирование:** Модель Gemini Flash оценивает снимки по 10-балльной шкале вайба и генерирует заголовок, мемное описание и тег по пяти ключевым корзинам[cite: 1, 7].
* **Отсев дубликатов и мусора:** Вычисление SHA-256 предотвращает повторный анализ файлов[cite: 1, 7], а эвристический фильтр удаляет превью Telegram (`_thumb` и файлы меньше 15 КБ)[cite: 1, 7].
* **Оптимизация трафика:** Автоматический ресайз и сжатие снимков через Pillow (до 1200×1200px, JPEG 85%) для быстрой загрузки галереи[cite: 1, 7].
* **Интерактивное кадрирование в админке:** Возможность двигать прямоугольник с пропорциями карточки витрины (280×230) для точной настройки фокуса (`object-position`) с затемнением области вне кадра[cite: 2].
* **Быстрая модерация с хоткеями:** Проверка очереди прямо с клавиатуры (`[A]` — одобрить в состав, `[D]` — отправить в брак)[cite: 2, 7].
* **Двусторонняя связь через облако (JSONBin.io):** Посетители сайта могут отправлять кадры в предложку или запрашивать удаление и правку карточек[cite: 7]. Локальный бэкенд опрашивает облако каждые 25 секунд[cite: 5, 7].
* **Мини-игра Sugar Rush 7×7:** Встроенный в сайт слот с кластерными выплатами от 5 символов, каскадами падений (Tumble), накапливаемыми спот-множителями до x128, покупкой бонуски за 100x и лимитом выигрыша 5000x[cite: 10, 11, 13, 14].

## 🧰 Стек технологий

* **Язык разработки:** Python 3.10+
* **AI Core:** Google Gemini API (`gemini-3.8-flash` с ротацией пула ключей и кулдаунами ошибок 429/503)


* **Обработка графики:** Pillow (PIL)


* **Облачный буфер:** JSONBin.io REST API v3


* **Фронтенд:** Vanilla HTML5, CSS Grid / Flexbox, JavaScript ES6 (Fetch API, DOM Events)


* **Хостинг:** GitHub Pages + собственный DNS (CNAME)

## 🔄 Ежедневный рабочий процесс

1. **Загрузка фото:** Поместите новые снимки в папку `incoming/`.


2. **AI-анализ:** Запустите `run.bat` (или команду `python auto_curator.py`). Кадры со Score $\ge 5$ оптимизируются и попадут в `pending/`.


3. **Модерация:** Запустите `admin.bat`. В открывшейся вкладке (`http://localhost:8080/admin.html`):


* Во вкладке **«Очередь»** настройте положение рамки кадрирования на фото и нажмите `[A]` (Одобрить) или `[D]` (В брак).


* Во вкладке **«Заявки посетителей»** проверьте пришедшие предложения и правки, отредактируйте текст при необходимости и нажмите «Применить».




4. **Публикация:** Запустите `push.bat`. Изменения запишутся в Git и через 1–2 минуты отобразятся на сайте `site.gasmyas.me`.
