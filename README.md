## 📌 О проекте

Проект стилизован под сайт футбольного клуба с локальным юмором[cite: 7]. Система полностью автоматизирует разбор сотен фотографий из чатов Telegram[cite: 7]:

1. Нейросеть Gemini Flash анализирует снимки, выставляет балл вайба (1–10) и придумывает описания по пяти тематическим корзинам[cite: 1, 7].
2. Кадры с оценкой от 5 баллов оптимизируются и передаются в локальную админ-панель[cite: 1, 7].
3. Администратор настраивает кадрирование через интерактивную рамку и подтверждает публикацию горячими клавишами (`[A]` / `[D]`)[cite: 2].
4. Пользователи на сайте могут отправлять заявки в предложку и предлагать правки описаний карточек через облачный буфер JSONBin.io[cite: 7].
5. Для развлечения на сайте доступен полноценный игровой слот **Sugar Rush 7x7** с механикой кластеров и накапливаемыми множителями[cite: 10, 11, 14].

## ⚡ Ключевые возможности

- **AI-курирование:** мультимодальная модель отбирает удачные кадры и генерирует заголовок, панчлайн и тег[cite: 1, 7].
- **Защита от дублей и мусора:** проверка SHA-256 исключает повторный разбор[cite: 1, 7], эвристика удаляет превью Telegram (`_thumb` и файлы < 15 КБ)[cite: 1, 7].
- **Интерактивное кадрирование:** перемещаемый прямоугольник в админке с пропорциями карточки витрины (280x230) для точной настройки `object-position` с визуальным затемнением краев[cite: 2].
- **Управление с клавиатуры:** быстрая модерация в админке с хоткеями[cite: 2].
- **Асинхронная обратная связь:** фоновый опрос облака JSONBin.io раз в 25 секунд для забора пользовательских заявок[cite: 5, 7].
- **Игровой автомат Sugar Rush:** сетка 7x7, кластеры от 5 символов, каскады падений (Tumble), множители пятен до x128, покупка бонуски за 100x и лимит выигрыша 5000x[cite: 10, 11, 13, 14].

## 🍭 Правила мини-игры Sugar Rush 7x7

* **Кластерные выплаты:** выигрыш начисляется за группы от 5 одинаковых символов, соединенных по горизонтали или вертикали.


* **Каскады (Tumble):** сыгравшие символы взрываются, верхние падают вниз, а освободившиеся места заполняются новыми.


* **Пятна множителей (Multiplier Spots):** при первом взрыве клетка подсвечивается, при втором получает множитель x2, удваивающийся при каждом последующем взрыве вплоть до x128. Несколько множителей в одном кластере складываются.


* **Фриспины:** 3, 4, 5, 6 или 7 скаттеров (🚀) запускают 10, 12, 15, 20 или 30 бесплатных вращений. Во время фриспинов накопленные множители не сбрасываются между спинами.


* **Покупка бонуски:** мгновенная активация раунда фриспинов за 100x от выбранной ставки.


* **Лимит выигрыша (Max Win):** максимальная выплата ограничена значением 5000x от ставки.

## 🚀 Установка и запуск

1. Склонируйте репозиторий:

```bash
git clone [https://github.com/kfx-stud/friends-archive.git](https://github.com/kfx-stud/friends-archive.git)
cd friends-archive

```

2. Установите зависимости:

```bash
pip install -r requirements.txt

```

3. Создайте файл `.env` в корне проекта:



```env
GEMINI_API_KEYS=AIzaSyA...,AIzaSyB...
GEMINI_MODEL=gemini-3.8-flash
# HTTP_PROXY=[http://127.0.0.1:10809](http://127.0.0.1:10809)
# HTTPS_PROXY=[http://127.0.0.1:10809](http://127.0.0.1:10809)

```

## 🔄 Рабочий процесс

1. **Добавление фото:** положите файлы в `incoming/` и запустите `run.bat`.


2. **Модерация:** запустите `admin.bat`, откройте `http://localhost:8080/admin.html`, настройте кадрирование и примите решения.


3. **Публикация:** запустите `push.bat` для отправки изменений на GitHub Pages.
