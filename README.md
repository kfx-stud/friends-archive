# 📸 ФК ГазМяс — Автономный AI Медиа-Портал

Автоматизированный конвейер курирования, фильтрации, модерации и публикации медиа-архива компании на базе Google Gemini API и GitHub Pages[cite: 7].

Проект стилизован под сайт футбольного клуба с локальным юмором[cite: 7, 8]. Он избавляет от необходимости вручную разбирать сотни фотографий из Telegram-чатов[cite: 7]: нейросеть оценивает снимки, генерирует остроумные описания, передает контент в локальную админ-панель для утверждения и публикует готовые карточки на статическом веб-сайте[cite: 7].

---

## ⚡ Ключевые возможности

- **Автоматическая оценка снимков (AI Curation):** Мультимодальная модель Gemini Flash анализирует кадры, присваивает оценку (Score 1–10) по шкале вайба/юмора и генерирует заголовок, мемное описание и тег[cite: 7, 12].
- **Защита от дубликатов и мусора:** Вычисление SHA-256 хешей предотвращает повторную обработку[cite: 7], а эвристический фильтр удаляет превью-файлы Telegram (`_thumb`, файлы менее 15 КБ)[cite: 7].
- **Оптимизация трафика и изображений:** Автоматический ресайз и сжатие исходников в оптимизированный JPEG (Pillow)[cite: 7].
- **Двусторонняя обратная связь через облако (JSONBin.io):** Посетители сайта могут отправлять идеи в предложку или запрашивать правки/удаление карточек[cite: 10, 11]. Локальный сервер забирает эти заявки из облачного буфера в фоновом режиме.
- **Интерактивная админ-панель:** Быстрая модерация очереди с горячими клавишами (`[A]` — одобрить, `[D]` — отсеять)[cite: 10], а также встроенное редактирование пользовательских заявок перед публикацией.
- **Интерактивный фронтенд:** Раздел новостей и статей клуба, живой поиск, фильтрация по тегам и встроенная мини-игра «Sugar Rush» с механикой барабанного слота и множителями[cite: 11].

## 🧰 Стек технологий

* **Язык разработки:** Python 3.10+


* **AI Core:** Google Gemini API (`gemini-3.8-flash` / REST API с автоматической ротацией пула ключей и кулдаунами)


* **Обработка графики:** Pillow (PIL)


* **Облачный буфер очереди:** JSONBin.io API v3


* **Фронтенд:** Vanilla HTML5, CSS Grid / Flexbox, Адаптивный UI, JavaScript (Fetch API, DOM Slots)


* **Хостинг:** GitHub Pages + кастомный DNS (CNAME)

## 🔄 Рабочий процесс (Workflow)

1. **Загрузка контента:** Сложите новые фотографии в папку `incoming/`.


2. **Анализ нейросетью:** Запустите `run.bat` (или `python auto_curator.py`). Скрипт отберет кадры со Score >= 5 и поместит их в `pending/`.


3. **Модерация:** Запустите `admin.bat`. В открывшемся браузере (`http://localhost:8080/admin.html`):


* Во вкладке **«Очередь»** просмотрите карточки (`A` — одобрить на сайт, `D` — в корзину).


* Во вкладке **«Заявки посетителей»** проверьте предложенные пользователями правки, отредактируйте текст при необходимости и нажмите «Применить».




4. **Публикация:** Запустите `push.bat`. Изменения запишутся в Git и через 1-2 минуты появятся на сайте.
